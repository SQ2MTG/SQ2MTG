## Function

A web departure-board application using public-transport data for three stops around the PKM Strzyża area.

The documented frontend stack is React, TypeScript and Tailwind CSS.

## Display behavior

The application is designed as a departure display rather than a general-purpose route planner. The existing project documentation describes approximately 30-second refresh behavior.
