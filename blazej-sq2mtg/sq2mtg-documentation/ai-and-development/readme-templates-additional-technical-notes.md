# README Templates — Additional Technical Notes

## Overview

A repository containing reusable README templates for SQ2MTG projects.

## Included templates

### React template

`README-React.md` provides a structure for React projects covering:

* project overview;
* badges;
* feature list;
* screenshots;
* technology stack;
* installation;
* usage;
* configuration;
* web interface;
* roadmap;
* contributing;
* license;
* author information.

### Python application template

`README-python_app.md` provides a broader infrastructure-oriented template with sections for:

* project description;
* features;
* screenshots;
* technologies and tools;
* hardware;
* project structure;
* Linux installation;
* usage;
* configuration;
* web interface;
* supported protocols;
* Docker;
* roadmap;
* contributing;
* license;
* author.

The template explicitly includes common SQ2MTG ecosystem technologies such as MQTT, APRS-IS, HTTP API, WebSocket, LoRa, KISS and RTL-SDR.

## Intended use

The repository is a documentation/template resource rather than an executable application.
