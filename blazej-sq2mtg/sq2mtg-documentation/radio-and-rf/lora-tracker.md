**Project type:** KiCad hardware prototype.

## Purpose

LoRa Tracker is a prototype PCB for an **ESP32 LoRa APRS/AX.25 modem** supporting radio modules such as **RA-01** and **E22-400M30S**.

## Hardware

The documented design covers:

* ESP32 controller;
* LoRa radio module interface;
* APRS / AX.25-oriented telemetry hardware;
* KiCad schematic/PCB design;
* alternative radio-module footprints and wiring variants.

The repository is a hardware design rather than a complete turnkey tracker application.

## Documentation boundary

Pin assignments, module variants, solder-pad options and firmware integration notes are documented in the technical reference. Verify the actual KiCad source before manufacturing a PCB revision.
