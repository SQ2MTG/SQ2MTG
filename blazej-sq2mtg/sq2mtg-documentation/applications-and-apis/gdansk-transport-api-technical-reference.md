## Function

Web application for displaying live GPS positions of public-transport vehicles in Gdańsk.

The documented frontend stack includes React, TypeScript, Tailwind CSS and Leaflet.

## Display model

The project is intended to visualize vehicle positions on a map. The documented UI behavior includes periodic refresh at approximately 5-second intervals and handling of vehicles that have stopped transmitting for more than approximately 20 minutes.
