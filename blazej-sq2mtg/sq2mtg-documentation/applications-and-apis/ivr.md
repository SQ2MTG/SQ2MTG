# IVR

## Repository status

* Repository: `SQ2MTG/ivr`
* Visibility: public
* Fork of `FreePBX/ivr`
* Default branch: `release/14.0`
* License: GPL-3.0
* SQ2MTG fork snapshot was pushed in August 2020.

## Project scope

This repository is the FreePBX **IVR module** for creating digital receptionist / auto-attendant menus. IVR menus can route callers to destinations such as extensions or other call-flow locations.

## Provenance

The repository metadata identifies `FreePBX/ivr` as the parent/source repository. The SQ2MTG repository should therefore be documented as a fork/snapshot of the FreePBX module, not as an original SQ2MTG implementation.

## Maintenance note

The fork is significantly older than the current upstream FreePBX repository. For current FreePBX deployment or development, use the current upstream source and verify compatibility with the target FreePBX release.
