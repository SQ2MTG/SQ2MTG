# README Rich Gen — summary

## Purpose

README Rich Gen is a public TypeScript/React application for generating rich repository README content from templates and repository analysis.

## Documented capabilities

Existing project documentation identifies:

* repository analysis based on GitHub project information
* template-driven README generation
* Gemini-assisted text generation
* preview/editor workflow
* local autosave
* rich Markdown generation
* optional web-search/deep-thinking generation modes

## Architecture

The project is based on a React/TypeScript frontend and Google AI Studio repository template. Gemini access and GitHub analysis are application-level integrations.

## Documentation boundary

Model names, API request schemas, GitHub permissions, rate limits and deployment-specific environment variables should be verified against source before being treated as stable interfaces.
