# README Templates — technical reference

## Purpose

Private repository containing reusable README/documentation templates for SQ2MTG projects.

## Repository metadata

* Branch: `main`
* License metadata: Apache-2.0
* Visibility: private

## Documented scope

The template material is intended to standardize project documentation and covers recurring SQ2MTG domains such as:

* hardware and embedded systems
* Linux
* Docker
* MQTT
* APRS-IS
* HTTP
* WebSocket
* LoRa
* KISS
* RTL-SDR

## Documentation policy

Templates should distinguish verified implementation details from project-specific assumptions. Secrets, private endpoints and credentials should never be embedded in reusable public-facing templates.
