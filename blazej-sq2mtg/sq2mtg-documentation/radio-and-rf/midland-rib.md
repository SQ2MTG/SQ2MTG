## Purpose

MID-RIB is a programming interface for Midland 70-xxx series radios. The repository description explicitly identifies **IDC10 and RJ45** radio-side interfaces.

## Project scope

The project belongs to the radio-programming / hardware-interface part of the SQ2MTG portfolio. The repository is private, so this page intentionally records only verified metadata and the documented project purpose.

For connector pinout, schematic, PCB files, programming protocol and build details, use the dedicated technical reference and the repository source.

## Technical reference

See **MIDLAND-RIB — Technical Reference** for the documented hardware and interface notes.

> This project should not be confused with a generic USB programming cable: the repository describes a specific Midland radio interface.
