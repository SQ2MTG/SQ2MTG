# Azimuthcontrol v2

NodeMCU/ESP8266 antenna rotator controller with azimuth sensing, target calculation, inertia compensation, timeout, travel limits, Wi-Fi configuration and persistent settings.

Documented pins include D0/GPIO16, D1/GPIO5, D2/GPIO4, D3/GPIO0 and A0.

Repository: `SQ2MTG/Azimuthcontrol_v2`.
