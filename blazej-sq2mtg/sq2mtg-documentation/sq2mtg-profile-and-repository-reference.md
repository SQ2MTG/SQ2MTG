## Documentation policy

Facts are separated from implementation inferences. API endpoints, hardware mappings, runtime dependencies and security-sensitive configuration are documented as verified only when confirmed from repository source or authoritative upstream documentation.

Credentials, API tokens, passwords and other secrets are not reproduced. Historical secret exposure should be documented as a security issue without exposing the credential, with rotation and externalization recommended where applicable.
