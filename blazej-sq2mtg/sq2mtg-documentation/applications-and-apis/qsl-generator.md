# QSL Generator

Web application for generating amateur-radio QSL cards.

## Repository status

* GitHub repository: `SQ2MTG/qsl-generator`
* Public fork of `RobbiNespu/qsl-generator`
* License metadata: MIT
* The repository is historical/reference-oriented; upstream should be treated as authoritative for current development.

## Runtime

The README documents two deployment paths:

* Docker Compose using the published container image.
* Local Flask execution with Python 3.8 and `requirements.txt`.

For local execution:

```bash
python3.8 -m pip install -r requirements.txt
flask run
```

The repository README does not define the complete application configuration, routes, forms, or image/font pipeline. Those details should be verified against the source before operational deployment.
