# autowx2 — Configuration Model

Glowny program korzysta z `autowx2_conf.py`. Konfiguracja okresla obserwowane satelity, harmonogramy, priorytety i zachowanie pluginow.

System rozdziela scheduler od modułów nagrywania/przetwarzania, dzieki czemu mozna dodawac kolejne workflow SDR bez przebudowy rdzenia.
