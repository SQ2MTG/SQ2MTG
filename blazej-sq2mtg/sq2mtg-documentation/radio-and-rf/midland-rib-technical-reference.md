## Project scope

This is a hardware-oriented radio programming interface project. The repository description identifies support for Midland 70-xxx series equipment and two physical connector variants: IDC10 and RJ45.

The repository is small and historical. The current documentation therefore records the verified repository metadata and project purpose without inventing an exact schematic, pinout, voltage level, programming protocol, or supported radio model list.

## Hardware and integration

* Target domain: Midland 70-xxx radio programming.
* Physical interface variants named by the repository: IDC10 and RJ45.
* Electrical levels, pin assignments, cable topology and radio-specific compatibility require direct inspection of the repository design files before being treated as authoritative.

## Maintenance status

Treat this as a historical project snapshot. Before building or connecting hardware, verify the actual design files and the electrical requirements of the specific Midland radio.

## Security and safety

Do not connect an unknown interface directly to a radio or computer until voltage levels and pin mapping are verified. Documentation intentionally does not reproduce credentials or other sensitive material.
