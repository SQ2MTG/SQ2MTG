# AI Projects — Integration Notes

Projekty AI w tym katalogu obejmuja lokalnego asystenta (`czarek`), narzedzia AI Studio/Gemini, aplikacje Android oraz workflow virtual try-on.

W dokumentacji rozdzielono trzy klasy backendow:

1. lokalne inference przez Ollama;
2. API modeli chmurowych przez klucze srodowiskowe;
3. inference obrazowe przez Hugging Face/ComfyUI.

Klucze API nie powinny byc commitowane do repozytoriow.
