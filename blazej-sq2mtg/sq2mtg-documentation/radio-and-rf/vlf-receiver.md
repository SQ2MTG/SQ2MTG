# VLF Receiver

**Repository:** `SQ2MTG/VLF-Receiver`\
**Project type:** hardware / receiver design.

## Purpose

VLF Receiver is a hardware design for receiving very-low-frequency signals and interfacing the receiver with a **PC sound card**.

## Repository contents

The documented project structure includes design artifacts such as:

* hardware/design JSON;
* PCB design data;
* bill of materials;
* Gerber manufacturing files.

This makes the repository primarily a reproducible hardware-design package rather than a finished software receiver.

## Engineering notes

The current repository documentation does not establish all details needed for a complete theory-of-operation, frequency calibration or end-to-end performance specification. Those items should therefore be verified against the actual schematic and PCB revision before construction.
