# Czarek — Distributed Local AI Assistant

Local AI assistant architecture using a Linux orchestrator/voice node and a Windows AI server.

Documented components include an HP T630 orchestrator, Windows 11 GPU server, WireGuard, Ollama, provider abstraction, model routing, health checks and FastAPI. The repository describes voice, memory and RAG components as an evolving implementation.

Current source should be treated as authoritative for status.
